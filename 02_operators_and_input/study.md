Operators are the various tools that allow us to evaluate and work with two or more variables.we have:
- Arithmetic Operators: Used to perform math on numbers
```python
print(10 + 3)   # addition -> 13
print(10 - 3)   # subtraction -> 7
print(10 * 3)   # multiplication -> 30
print(10 / 3)   # division -> 3.333... (always returns a float)
print(10 // 3)  # floor division -> 3 (drops the decimal)
print(10 % 3)   # modulus (remainder) -> 1
print(10 ** 3)  # exponent -> 1000
```

- Comparison Operators: Used to comapare two or more variables
```python
print(5 > 3)    # True
print(5 == 5)   # True (== checks equality)
print(5 != 3)   # True (not equal)
print(5 <= 4)   # False
```

- Logical Operators: Used to modify two or more expressions, returning a boolean value of true or false on the relationship between the inputs.
```python
print(True and False)  # False — both must be True
print(True or False)   # True — at least one True
print(not True)        # False — flips it
```
